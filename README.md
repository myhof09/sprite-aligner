# Sprite Aligner

AI가 만든 "가짜 픽셀아트" 스프라이트 줄(초록 배경, 간격 불규칙)을 깨끗한 픽셀아트 스프라이트 시트로 정리하는 웹 도구입니다.
**모든 처리는 브라우저 안에서만** 이루어지며 그림은 어디에도 업로드되지 않습니다. 설치·서버 없이 `index.html`만 열면 됩니다.

왼쪽 단계를 위에서부터 따라가면 됩니다. 버튼에 마우스를 올리면 짧은 설명이 나오고, 위쪽 **단축키 ?** 에 마우스·키보드 단축키가 있습니다.

## 사용 순서

1. **① 그림 열기** — PNG 열기(또는 창에 끌어다 놓기). 연습용은 **샘플로 연습하기**.
2. **② 자동 정리** — 열면 자동으로 실행됩니다 (배경은 **가장자리에서 연결된 배경만 지우기**가 기본: 그림 가장자리에서 이어진 배경만 지우므로 캐릭터 안의 같은 색 — 어두운 회색 배경 위의 검은 바지 등 — 은 남습니다. 회색 · 검정 · 흰 배경은 허용오차가 배경 자체의 잡음(JPG)에 맞춰 좁아지고, 체크무늬 배경은 두 색을 함께 배경으로 봅니다. 칸 테두리 선과 모서리의 작은 워터마크도 지웁니다. 고급 설정에서 배경 설정을 바꾸면 지워질 부분이 원본 창에 **빨갛게** 먼저 보이고, **적용** / **되돌리기**를 고릅니다): 배경 제거 → 프레임 찾기 → AI 픽셀 크기 감지 → 블록마다 가장 많은 색 → 팔레트 통일 → 자동 정렬. 결과가 이상하면 **고급 설정**에서 배경 색·허용오차·초록 테두리 지우기·AI 픽셀 크기(후보 버튼)·색 수·외곽선 등을 바꿉니다. 오른쪽 **전/후 비교 (8×)** 로 확인하세요.
   - **물든 테두리 → 외곽선 색** (고급 설정, 기본 꺼짐): 배경색이 물든 가장자리 픽셀을 옆의 어두운 외곽선 색으로 바꿉니다(새 색 없음). 꺼 두면 예전처럼 색 번짐만 지웁니다.
   - **부드러운 그림 (픽셀 처리 안 함)**: 가짜 픽셀아트가 아니라 부드럽게 칠한 그림(일러스트풍 캐릭터, 보스 그림 등)용입니다. 켜면 AI 픽셀 크기 찾기 · 블록 색 · 팔레트 · 외톨이 픽셀 · 외곽선을 하지 않습니다. 배경은 그대로 지우되(가장자리 연결 / 전체 모두 가능) 가장자리 2px은 배경색을 빼고 반투명으로 남겨 계단 없이 부드럽고, 초록 · 마젠타 배경 모두 색 번짐(despill)을 지웁니다. **축소 (원본 px ÷)** 칸은 크기 배율입니다(1 = 원래 크기, 2 = 절반, 고품질 축소). 머리 기준 크기 맞추기 · 자동 정렬 · 이펙트 지우기 · 내보내기는 그대로 씁니다. 미리보기도 부드럽게 줄여 보여 줍니다.
3. **③ 프레임 맞추기**
   - 원본 창의 박스: ↖ 선택 · ＋ 추가(드래그) · ✂ 분할(자를 곳 클릭) · ⧉ 병합 · 🗑 삭제
   - **자동 정렬**: 프레임마다 기준점을 찾아 가이드에 맞춥니다. 그다음 편집 창에서 드래그·방향키로 다듬습니다. **정렬 기준**:
     - **몸통 기준 정렬**: 머리·몸통 중심을 한 세로선에 맞춥니다 (다리·팔·무기는 빼고 계산). 발은 발 선에 두고, 원본에서 뛰어올라 그린 높이는 지켜서 점프가 납작해지지 않습니다. 달리기·걷기용입니다.
     - **발 기준**: 발 위치와 다리 중심을 맞춥니다 (공격·대기 동작).
     - **바닥선 기준 (쓰러짐)**: 그림 전체(무기 포함)의 가장 낮은 픽셀을 발 선에 두고, 가로 위치는 원본 줄의 같은 너비 칸 안에서 그려진 자리를 지킵니다. 쓰러지는 몸이 가운데로 끌려오지 않습니다(죽음 · 넘어짐).
     - **자동**(기본): 이름에 run / walk / 달리 / 걷 이 들어가면 몸통 기준, 아니면 발 기준입니다.
   - 편집 창 위 도구: ✥ 이동 · ✏ 연필 · ⌫ 지우개 · 💧 스포이트 · 🪄 요술봉 · ▭ 사각형 · ➰ 올가미 · ◎ 임팩트 지점 · ↶↷ 되돌리기
   - **이펙트 지우기**: 요술봉/사각형/올가미로 고른 뒤 선택 지우기, 또는 몸에 붙지 않은 **떨어진 조각** 자동 지우기(미리보기 → 적용). 현재 프레임/모든 프레임, **FX 레이어로 옮기기** 선택 가능.
   - 아래 필름: 프레임 시간(ms), ☆ 임팩트 프레임, ⧉ 복제 · ◀ ▶ 순서 · ✕ 삭제
   - **크기 맞추기 (머리 기준)**: AI가 프레임마다 조금씩 다른 크기로 그렸을 때. 원본에서 한 프레임의 머리를 상자로 감싸면 모든 프레임에서 머리를 찾아 크기를 비교하고(5% 넘게 다르면 ⚠), **머리 크기에 맞추기**로 프레임마다 AI 픽셀 크기를 맞춥니다. 프레임별 값은 손으로도 바꿀 수 있고, 비교 창 "기준 프레임과"로 나란히 확인합니다. (② 고급 설정의 "프레임마다 AI 픽셀 크기 따로"는 자동 추정이라 흔들릴 수 있어, 머리 기준이 더 정확합니다.)
4. **④ 이펙트**
   - **✨ 자동 이펙트**: 칼끝(밝은 회색의 길고 가는 덩어리 끝)을 프레임마다 찾아, 빠르게 휘두르는 구간에 실제 칼끝 경로를 따라가는 궤적(속도에 따라 두께, 휘두른 뒤 2프레임 동안 사라짐)을, ★ 임팩트 프레임의 칼끝에 타격 불꽃을, 발이 크게 움직이는 프레임에 먼지를 넣습니다. 스타일: 기본(흰·파랑) · 금빛 · 화염 · 얼음 · 먹(잉크) · 번개, 궤적 모양 선택. 칼끝은 노란 ◆로 편집 창과 필름에 보이고, 끌어서 고치면 바로 다시 그립니다.
   - **베기 레시피 14종**(가로 · 올려 베기 · 내려찍기 · 십자 · 발도 섬광 · 잔상 초승달 · 연속 · 바람 칼날 · 먹 붓 · 불꽃 · 얼음 · 번개 · 회전 · 올려치기)과 **🖼 갤러리**(움직이는 미리보기).
   - **베기 조절**(`slash` 레이어가 있는 레시피면 가져온 것도 적용): 궤적 모양 11종(가는 초승달 · 두꺼운 반달 · 점점 가늘게 · 혜성 · 물결 띠 · 끊어진 호 · 톱니 · 두 줄 · 나선 · 지그재그 · 완전한 원), 방향 · 휘어짐 · 반경 · 두께 · 사라지는 속도 · 반짝이 개수, 색 테마(흰·파랑 · 금색 · 빨강 · 먹 · 얼음 · 화염 · 번개). 프로젝트에 저장됩니다.
   - 가져오기: 이펙트 시트 PNG + 메타 JSON(이 도구, Aseprite 배열/해시, `frameWidth/frameHeight`), 한 장짜리 그림, 또는 ③의 **FX 레이어**.
   - **레시피(JSON) 가져오기**: 이 도구의 **sa-fx@1** 레시피(.safx.json, 형식은 [docs/fx-format.md](docs/fx-format.md))를 브라우저에서 바로 그립니다. 레이어(베기 호 · 직선 · 고리 · 불꽃 파티클 · 번개 · 빛 · 섬광 모양 · 연기/먼지 · 그림), 키프레임, 시드 고정, 팔레트 밴드, 픽셀 그대로. `blend`와 `impactFrame`이 기본값이 되어, 레시피의 임팩트 프레임이 캐릭터의 ★ 임팩트 프레임에 맞춰 재생됩니다. JSON 칸을 고치면 바로 다시 그리고, 크기 · 색상 돌리기 · 속도 슬라이더가 있습니다. 그 밖의 레시피 9개: 기본 베기 궤적 · 타격 불꽃 · 번개 내려치기 · 불꽃 폭발 · 먼지 퍼짐 · 치유 빛 · 충격파 · 기운(반복) · 연기. 예전 `pxf.graph@1` 레시피는 지원하지 않습니다(예전 프로젝트를 열면 알려 주고 빈 이펙트로 남겨 둡니다: 다시 만들어 주세요).
   - 기본 이펙트(코드로 그림): 베기 궤적 · 타격 불꽃 · 발 먼지 · 칼날 반짝임 (색 · 크기).
   - 이펙트마다: 시작 프레임 · 길이, 정수 배율, 회전(90° 단위 또는 자유, 픽셀 맞춤), 뒤집기, 블렌드(보통 / 더하기 / 스크린), 불투명도.
   - **임팩트 지점에 붙이기**, **칼끝 따라가기**(프레임별 키프레임, **칼끝 자동 찾기**). 편집 창 ✦ 도구(X)로 끌어 옮깁니다.
5. **⑤ 재생·확인** — 재생/반복(이펙트 포함), 왼쪽 보기(좌우 반전), **게임 크기로 보기**(게임 칸 62px 기준, 게임 배율, 배경 그림).
6. **⑥ 내보내기** — **프레임 PNG**(프레임마다 한 장, 시트와 같은 칸·정렬: `이름_frame_01.png` …)와 **타이밍 JSON**(`이름_timing.json`: 파일 · 시간 ms · 임팩트 · 기준점)도 따로 내보낼 수 있습니다. **모두 내보내기**: 시트 PNG + 메타 JSON + 미리보기 GIF (+ 왼쪽 버전 `_left.png`, FX가 있으면 `_fx.png`). 이펙트는 기본으로 **따로 시트**(`_effect1.png`…, 위치·타이밍·블렌드는 메타 JSON `effects`)이고, **캐릭터에 합치기**도 고를 수 있습니다. **여러 파일 일괄 처리**로 같은 설정을 여러 PNG에 적용할 수 있습니다.

위쪽 **프로젝트 저장/열기**: 원본 그림, 설정, 위치, 손으로 고친 픽셀, FX 레이어를 `.json` 하나로 저장해 나중에 이어서 편집합니다.

## 명령줄 (일괄 · 자동화)

브라우저 창 없이 시트 하나를 처리해 프로젝트 파일과 내보내기 파일을 만듭니다. 웹 도구와 같은 코드(`index.html`)를 Playwright로 화면 없이 돌리므로 결과가 똑같고, 프로젝트는 웹 도구에서 열어 손으로 다듬을 수 있습니다.

```
npm i -D playwright          # 한 번 (또는 PLAYWRIGHT_DIR=Playwright가 설치된 폴더)
node tools/cli.mjs attack.png --out out --smooth --all-bg --fringe --pad 16 --align feet      --durations 160,80,60,200,100,140 --impact 3 --no-loop
```

옵션: `--name` · `--smooth` (부드러운 그림) · `--shrink N` · `--pixel N` (AI 픽셀 크기, 없으면 감지) · `--key #rrggbb` · `--tol N` · `--all-bg` (가장자리 연결만이 아니라 모든 배경) · `--fringe` · `--despill 0..1` · `--pad N` · `--align auto|feet|torso|ground` · `--durations` · `--impact N|none` · `--no-loop` · `--left` · `--outputs project,all,frames,timing` (기본: 넷 다) · `--row N` (여러 줄 시트의 N번째 줄만, 1 = 맨 위; 줄은 빈 가로 틈으로 찾음) · `--frames N` (기대 프레임 수, 다르면 경고) · `--remap "#src>#dst,tol"` (여러 번 가능: 그 색 근처·같은 색조의 픽셀을 명암은 지키며 옮김, 예: 다른 시트의 옷 색 맞추기) · `--target-height PX` + `--target-frame K` (부드러운 그림: K번째 프레임이 PX 높이가 되도록 한 배율로 맞춤).
나오는 파일: `이름.sprite-aligner.json`, `이름.png` + `.json` + `_preview.gif` (+ 왼쪽/FX/이펙트 시트), `이름_frame_01.png` …, `이름_timing.json`.
**동영상에서 걷기 (`--video walk.mp4`)**: 프레임을 뽑고(ffmpeg가 있으면 ffmpeg, 없으면 Edge / Chrome으로 디코딩), 실루엣(다리)을 비교해 이음매 없는 한 걸음 주기(두 발, `--loop-steps 2`)를 찾아 고르게 N장(`--loop-pick 8`)을 골라 한 줄 시트처럼 처리합니다. 직접 고르려면 `--pick-frames 0,2,5,…`, 뽑은 프레임 저장은 `--keep-frames DIR`. 결과의 `loop`에 주기 · 시작 · 고른 프레임 번호가 나옵니다. 색 바꾸기 규칙에 `box: [x0, y0, x1, y1]`(원본 px)를 주면 그 영역만 바꿉니다.

**작업 파일 (`--spec job.json`)**: `run`의 옵션을 JSON으로 적습니다(경로는 파일 기준 상대). 저장한 프로젝트를 다시 써서(`"project"`, `"pick": [0,0,0,1,…]` 프레임 고르기·반복) 이펙트를 얹을 수 있습니다: `"effects": [{ "recipe": "x.safx.json" | "sheet": { "png", "json" }, "start", "len", "at": { "from": "feet|center|head|tip|point", "x", "y", "dx", "dy", "frame" }, "scale", "blend", "opacity", "under": true(몸 뒤) }]`, `"expand": [왼, 위, 오른, 아래]`(이펙트 자리), `"timingExtra"` / `"frameExtra"`(타이밍 JSON에 넣을 값), 출력 `fxframes`(프레임마다 이펙트만: `이름_fx_01.png`). 웹 화면의 이펙트에도 **몸 뒤에 그리기**(under)가 반영됩니다.

**부위 기준점 (`--anchor-out name=PART --anchor-color #rrggbb [--anchor-box x,y,w,h] [--anchor-tol 40] [--anchor-point bbox|mean|extreme|lowest]`)**: 프레임마다 그 색의 가장 큰 덩어리를 찾아 타이밍 JSON의 `frames[].PART = {x, y}`(셀 px)에 적습니다. 여러 번 줄 수 있고(`--anchor-out`마다 새 기준점), 작업 파일에서는 `"anchors": [{ "name", "color", "tol", "box": [x, y, w, h], "point", "frames": [0, 2] }]`. 점: `bbox` (기본, 덩어리 상자 가운데: 방패 면), `mean` (무게중심), `extreme` (몸 중심에서 가장 먼 점: 지팡이 수정 끝), `lowest` (맨 아래: 땅에 닿는 점). 지운 픽셀·섬 제거가 끝난 프레임에서 찾습니다.

**조각 떼어내기 (`--extract name=PIECE --extract-frame N [--extract-at x,y | --extract-box x,y,w,h] [--extract-erase 2,3] [--extract-file 경로] [--extract-pivot ground|center]`)**: 웹 도구의 "FX 레이어로 옮기기"를 파일로. 프레임 N(0부터)에서 그 점의 조각(또는 상자 안 가장 큰 떨어진 조각)을 골라(불투명 > 40인 픽셀 + 몸에 닿지 않는 2 px 안쪽 흐린 가장자리) `PIECE.png` + `PIECE.json`(기준점: 바닥 가운데 / 가운데, 캐릭터 기준점에서의 offset)으로 내보내고, 고른 프레임들에서 지웁니다(손 수정으로 남아 웹 도구에서 되돌릴 수 있음). 타이밍 JSON에 `props.PIECE = { file, frame, offset }`; 작업 파일에서는 `"extract": [{ …, "showFrame", "offsetKey": "trapOffset", "frameKey": "trapFrame" }]`로 원하는 키 이름에도 씁니다. 프레임 번호는 모두 0부터(impactFrame과 같음).

**색 비교 (`node tools/cli.mjs measure frame.png --ref master.png [--box x,y,w,h] [--ref-box …] [--colors 14] [--min-share 2] [--min-diff 12]`)**: 두 그림의 불투명 픽셀을 함께 군집으로 나눠, 군집마다 프레임 쪽 중앙값과 마스터 쪽 중앙값을 비교하고 `--remap '#src>#dst,tol'` 제안을 출력합니다. 같은 색 계열(색상 30° 안, 또는 둘 다 회색조)만 짝짓고, 따뜻한 색(피부·갈색·금색)은 보여만 주고 제안하지 않습니다(금색 부품은 `box`를 준 규칙으로 직접). 작은 부품은 `--box`와 낮은 `--min-share`로 그 영역만 재세요.
주의: `--row`를 쓰면 색 바꾸기 규칙의 `box`는 그 줄을 잘라낸 그림 기준 px입니다(결과의 `row.y[0]`만큼 위에서 뺌).

페이지 안에서는 `window.SpriteAligner.run({...})`로도 부를 수 있습니다(같은 옵션, 파일을 base64로 돌려줌).

## 메타 JSON 예

```json
{
  "image": "hero_attack.png",
  "frameWidth": 127, "frameHeight": 93, "frameCount": 8,
  "frames": [{ "index": 0, "x": 0, "y": 0, "w": 127, "h": 93, "duration": 300 }],
  "durations": [300, 150, 40, 40, 120, 150, 250, 200],
  "pivot": { "x": 63, "y": 91 },
  "impactFrame": 4,
  "impactPoint": { "x": 90, "y": 40 },
  "left": { "image": "hero_attack_left.png", "pivot": { "x": 64, "y": 91 } },
  "fx": { "image": "hero_attack_fx.png" },
  "effects": [{
    "name": "타격 불꽃", "image": "hero_attack_effect1.png", "frameWidth": 23, "frameHeight": 23, "frameCount": 4,
    "blend": "add", "opacity": 1, "startFrame": 4, "length": 4,
    "frames": [{ "charFrame": 4, "effectFrame": 0, "x": 89, "y": 29, "leftX": 15 }]
  }]
}
```

`effects[].frames`: 캐릭터 프레임 `charFrame`이 보이는 동안 이펙트 시트의 `effectFrame`을 캐릭터 칸 안 `(x, y)`에 그립니다. 왼쪽 보기는 이펙트를 뒤집고 `leftX`를 씁니다.

`pivot`은 중심선 x와 발 기준선 y입니다(픽셀 경계 좌표).

## ✨ 이펙트만 모드

위쪽 **✨ 이펙트만**(또는 주소 끝 `#fx`): 캐릭터 없이 스킬 이펙트만 만듭니다.

- **캔버스 크기** 32 · 48 · 64 · 96 · 128 — 레시피는 비율을 지켜 이 크기로 그립니다.
- **레시피 갤러리**: 분류 칩(전체 · ★ 즐겨찾기 · 베기 · 찌르기 · 타격·둔기 · 투사체 · 폭발 · 화염 · 전기 · 얼음 · 독·산 · 물 · 바람 · 땅·바위 · 빛·치유 · 어둠 · 먹·책략 · 상태이상 · 버프·디버프 · 소환·순간이동 · 연기·먼지 · 기타 · **삼국지 TD** · 내 이펙트), 이름·태그 검색, 이름순 / 새 것부터, ☆ 즐겨찾기. 전체에서는 분류마다 접을 수 있고, 마지막 분류 · 정렬 · 즐겨찾기 · 접힘을 기억합니다. 썸네일은 가장 꽉 찬 프레임을 보여 주고 마우스를 올리면(휴대폰: 누르는 동안) 움직입니다. 레시피의 분류와 태그는 JSON의 `category`(여러 개면 목록, 첫째가 주 분류) / `tags`. 분류마다 기본 레시피가 6개 이상 있습니다(`js/safx-more.js`, 105개). 삼국지 TD 분류는 samguk-td의 스킬 이펙트 레시피를 `node tools/import-samguk.mjs`로 `js/safx-samguk.js`에 담은 것으로, 그림 레이어 · 원소 팔레트 · 이름으로 화염 · 전기 · 투사체 같은 분류에도 함께 들어갑니다, **레시피 열기/저장**(.safx.json, sa-fx@1), **JSON 편집**(고치면 바로 다시 그림).
- **조절**: 색상 돌리기 · 속도 · 블렌드(add / screen / normal) · 임팩트 프레임(필름에서 더블클릭) · 임팩트 멈춤 ms · 반복. `slash` 레이어가 있는 레시피는 베기 조절(모양 · 색 테마 · 방향 · 휘어짐 · 반경 · 두께 · 사라지는 속도)도.
- **미리보기**: 확대 보기, 게임 배경 위 게임 칸(기본 62px) 가운데에 실제 크기로, 블렌드 적용.
- **내보내기**: 시트 PNG(가로 한 줄) + 메타 JSON. **내 이펙트** 목록(브라우저에 저장)에 담아 두고 체크한 것(없으면 전부)을 **.zip 하나**로 일괄 내보내기: 이펙트마다 `<이름>.png` + `<이름>.json`, 그리고 목록 `effects.json`.

```json
{
  "name": "불꽃 폭발", "image": "불꽃_폭발.png",
  "frameWidth": 64, "frameHeight": 64, "frameCount": 20, "columns": 20, "rows": 1,
  "fps": 24, "durations": [42, 42, 42, 42, 122, 42], "durationMs": 920, "loop": false,
  "impactFrame": 4, "impactMs": 168, "blend": "add", "pivot": { "x": 32, "y": 32 },
  "frames": [{ "index": 0, "x": 0, "y": 0, "w": 64, "h": 64, "duration": 42 }],
  "source": { "format": "sa-fx@1", "recipe": { }, "size": 64, "hue": 0, "speed": 1, "impactHold": 80 }
}
```

Phaser: `this.load.spritesheet(key, image, { frameWidth, frameHeight })`, 애니메이션 프레임마다 `duration`, `blend`는 `ADD` / `SCREEN` / `NORMAL`, 타격 판정은 `impactMs`에. `source.recipe`로 같은 이펙트를 다시 열 수 있습니다.
