# Sprite Aligner

AI가 만든 "가짜 픽셀아트" 스프라이트 스트립(초록 배경, 간격 불규칙)을 깨끗한 픽셀아트 스프라이트 시트로 정리하는 웹 도구입니다.
**모든 처리는 브라우저 안에서만** 이루어지며 이미지는 어디에도 업로드되지 않습니다. 설치·서버 없이 `index.html`만 열면 됩니다.

## 사용 순서

1. **PNG 열기** (또는 파일을 창에 끌어다 놓기). 연습용은 **샘플** 버튼.
2. **배경 제거**: 키 색은 테두리에서 자동으로 잡힙니다. 다르면 **스포이트**로 원본을 클릭. 허용오차·가장자리·디스필로 초록 테두리를 없앱니다. 알파는 항상 완전 불투명/완전 투명입니다.
3. **프레임**: 연결된 영역으로 자동 감지됩니다. 원본 창에서
   - 선택: 클릭 (Shift+클릭 = 여러 개) → **병합** / **삭제**
   - 박스 추가: 드래그
   - 분할: 자를 x 위치를 클릭
4. **픽셀**: 가짜 픽셀 크기는 자동 감지되고, 다른 후보는 버튼으로 바로 바꿀 수 있습니다. 블록마다 **가장 많은 색**(평균 아님)을 고른 뒤 주요 색 팔레트로 스냅합니다(색 수 0 = 끄기). 오른쪽 **전/후 비교 (8×)** 로 확인하세요.
5. **정렬**: 편집 창에서 프레임을 드래그하거나 방향키(1px, Shift = 5px). 가이드 선(발 / 머리 / 무기 / 중심)은 드래그로 옮기고, **스냅**을 켜면 3px 안에서 붙습니다. `,` `.` 로 이전/다음 프레임, 스페이스로 재생.
6. **어니언 스킨**, **픽셀 격자**, 프레임별 시간(ms, 아래 필름 스트립), **반복** 재생 미리보기.
7. **내보내기**: 시트 PNG(같은 크기 칸), 메타 JSON(프레임 크기, 시간, pivot, impactFrame), 미리보기 GIF.
8. **프로젝트 저장/열기**: 원본 이미지와 모든 설정·위치를 JSON 하나로 저장해 나중에 다시 편집합니다.

## 메타 JSON 예

```json
{
  "image": "hero_attack.png",
  "frameWidth": 126, "frameHeight": 93, "frameCount": 8,
  "frames": [{ "index": 0, "x": 0, "y": 0, "w": 126, "h": 93, "duration": 300 }],
  "durations": [300, 150, 40, 40, 120, 150, 250, 200],
  "pivot": { "x": 63, "y": 91 },
  "impactFrame": 4
}
```

`pivot`은 중심선 x와 발 기준선 y입니다(픽셀 경계 좌표).

## 파일

- `index.html`, `css/style.css` — 화면
- `js/imageops.js` — 이미지 처리 (키잉, 영역 감지, 픽셀 크기 감지, 축소, 팔레트)
- `js/gif.js` — GIF 인코더
- `js/sample.js` — 샘플 스트립 생성
- `js/app.js` — 상태와 UI
